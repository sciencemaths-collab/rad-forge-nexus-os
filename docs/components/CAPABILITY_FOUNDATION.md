# Phase 1: Capability Foundation

Status: TESTED | Boundary contract: 1.0

RAD now has one provider-neutral capability vocabulary for its native tools and future compute,
optimization, decision, connector, hardware, and domain implementations. Manifests are strict,
versioned, canonical, and content-addressed. Registration is duplicate-safe; discovery is
side-effect-free and excludes implementation objects; routing is qualification-, expiry-,
effect-, network-, timeout-, and memory-bound and rejects ambiguous versions.

Native tools are adapted without changing their governed executor semantics. Registration does
not grant qualification, policy authority, approval, network access, or execution authority.
Remote node discovery, durable registries, engine lifecycle supervision, federation, and
commercial entitlements remain explicitly assigned to later roadmap phases.
